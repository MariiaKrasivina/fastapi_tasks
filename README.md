# FastAPI Tasks - Трекер задач

Простое и эффективное приложение для управления задачами, построенное на FastAPI с использованием асинхронной БД SQLite.

## 📋 Описание

**fastapi_tasks** — это REST API сервис для отслеживания задач (To-Do список). Приложение позволяет:
- ➕ Добавлять новые задачи
- 📖 Просматривать все задачи
- 📝 Добавлять описания к задачам

## 🚀 Требования к окружению

- Python 3.10+
- pip или другой пакетный менеджер

## 📦 Установка и запуск

### 1. Клонируйте репозиторий
```bash
cd fastapi_tasks
```

### 2. Создайте виртуальное окружение
```bash
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Запустите приложение
```bash
uvicorn main:app --reload
```

Приложение будет доступно по адресу: **http://127.0.0.1:8000**

## 📚 API Документация

FastAPI автоматически генерирует интерактивную документацию:
- **Swagger UI**: http://127.0.0.1:8000/docs
- **ReDoc**: http://127.0.0.1:8000/redoc

### Endpoints

#### 1. Добавить задачу
```http
POST /tasks
Content-Type: application/json

{
  "name": "Название задачи",
  "description": "Описание (опционально)"
}
```

**Ответ (200 OK):**
```json
{
  "ok": true,
  "task_id": 1
}
```

#### 2. Получить все задачи
```http
GET /tasks
```

**Ответ (200 OK):**
```json
[
  {
    "id": 1,
    "name": "Купить продукты",
    "description": "Молоко, хлеб, масло"
  },
  {
    "id": 2,
    "name": "Написать доклад",
    "description": null
  }
]
```

## 💡 Примеры использования

### Через curl

Добавить задачу:
```bash
curl -X POST "http://127.0.0.1:8000/tasks" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Позвонить другу",
    "description": "Обсудить встречу"
  }'
```

Получить все задачи:
```bash
curl "http://127.0.0.1:8000/tasks"
```

### Через Python (requests)

```python
import requests

# Добавить задачу
response = requests.post(
    "http://127.0.0.1:8000/tasks",
    json={"name": "Важная задача", "description": "Срочно!"}
)
print(response.json())

# Получить задачи
response = requests.get("http://127.0.0.1:8000/tasks")
print(response.json())
```

## ⚙️ Жизненный цикл приложения

Приложение использует `lifespan` контекстный менеджер для управления жизненным циклом:
- ✅ По запуску приложения: очищает старую БД и создает новые таблицы
- ✅ При остановке: выполняет логирование выключения

## 📝 Заметки

- База данных автоматически **очищается при каждом запуске** приложения
- Используется **асинхронный** подход для работы с БД
- Все операции с БД выполняются **асинхронно** для лучшей производительности
